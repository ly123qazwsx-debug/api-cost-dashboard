# 其余 API 平台 - 费用趋势看板

## 文件

- `API-Cost-Dashboard.html`：看板本体（单文件）。用 **Chrome / Edge 打开** 查看图表，不要只在 Cursor 里看源码。
- 保存 HTML 后，浏览器 **Ctrl+F5** 强刷即可看到最新数据。

> **常见误解**：在飞书里改了数，只刷新看板页面 **不会** 更新。数字写在 HTML 的 `platforms` 里，必须 **改文件 → 保存 → 再强刷浏览器**。

## 数据来源

飞书多维表格 **「其余API日耗」**（工作簿「AI-平台消耗」内）。

- **当前截止日**：**10/18**。飞书「其余API日耗」10/19 及之后原币种为空（人民币列显示 0），不把空行算进累计。
- **当期**：10/1–10/18；**对比期**：9/1–9/18；**上月整月**：9 月合计（¥107,245.97）。整月预估 `est = mtd ÷ 18 × 31`。
- 走势图 `week` 使用 **原币种** 日耗；顶部合计、占比、`mtd`/`d27`/`d26` 为飞书人民币结算列（美元平台按表内人民币列，汇率 6.7108）。

## 每日更新步骤

### 1. 在飞书填好当日数据

确认截止日各平台的日耗、余额、月累计等与表一致。

### 2. 用 Cursor 打开本文件夹，编辑 `API-Cost-Dashboard.html`

数据区在 `<script>` 开头（约 **212–233 行**）。

#### （1）`MTD_DAYS`

```javascript
const MTD_DAYS = 18;  // = 截止日是本月第几天（截止 10/18 则填 18）
```

#### （2）每个平台的 `platforms` 一行

| 字段 | 说明 |
|------|------|
| `week` | **7 个数**，从旧到新 = 最近 7 个自然日原币种日耗；保存后 **预估折线自动重算** |
| `bal` | 账户余额（原币种） |
| `mtd` | 本月 1 日～截止日累计 |
| `augSame` | 上月 1 日～上月**同一天**累计 |
| `augFull` | 上月整月累计 |
| `d26` / `d27` | **前一日 / 截止日**消耗（供顶部卡片、明细表；与当前文件人民币汇总口径保持一致） |
| `est` | 预估本月总消耗：`mtd ÷ MTD_DAYS × 31`（10 月 31 天） |
| `cur` | `"USD"` 或 `"CNY"`，一般不用改 |

#### （3）走势图横轴日期（每往前滚 1 天改一次）

```javascript
const WEEK_LABELS = ["10/12", "10/13", "10/14", "10/15", "10/16", "10/17", "10/18"];
const FC_LABELS   = ["10/19", "10/20", "10/21", "10/22", "10/23", "10/24", "10/25"];
```

#### （4）页面上的日期文案

全文搜索替换（示例：截止日从 9/27 改为 9/28）：

| 查找 | 替换为 |
|------|--------|
| `9/1–9/27` | `9/1–9/28` |
| `8/1–8/27` | `8/1–8/28` |
| `9/27` | `9/28` |
| `9/26` | `9/27` |
| `9/21–9/27` | `9/22–9/28` |
| `9/28–10/4` | `9/29–10/5` |

注意：替换时避开误改（可先改带前缀的 `9/1–9/27`，再改「昨日 9/27」等）。明细表表头里的 `9/27`、`较 9/26` 在 `columns` 数组中，需一并改。

### 3. 保存并在浏览器查看

1. **Ctrl+S** 保存。  
2. 双击 HTML 用浏览器打开，或刷新已打开页。  
3. **Ctrl+F5** 强刷。标题旁版本号会随我们改版变化；改完数据后至少应能看到新 `week` 与日期。

## 填写示例：截止日从 9/27 滚到 9/28

假设飞书里 **MiniMax（美元）** 最近 7 天日耗为：

`9/22→4.72, 9/23→0, 9/24→1.3, 9/25→0, 9/26→0.8, 9/27→11.04, 9/28→8.50`

则只改该平台的 `week` 最后一格并整体左移一天：

```javascript
// 改前
week: [4.72, 0, 1.3, 0, 0.8, 11.04, 7.44],

// 改后（去掉 9/21，追加 9/28）
week: [0, 1.3, 0, 0.8, 11.04, 7.44, 8.50],
```

同时更新：

```javascript
const MTD_DAYS = 28;
// MiniMax 若 d27/d26 表示最近两天（按你文件口径从表抄数）
// d27: 9/28 日耗折人民币或原币——与现有 platforms 其它字段口径一致
// mtd、bal 从飞书更新
```

`WEEK_LABELS` / `FC_LABELS` 按上表各加一天即可。

**GRS（人民币）** 示例：若 7 天为 572.69 … 520.33，新增 9/28 为 510.00：

```javascript
week: [576.18, 643.87, 823.63, 698.63, 520.33, 510.00],  // 仍保持 7 个数
```

（实际请从表抄齐 7 天，不要漏日。）

## 不必手改的部分

- 各平台 **消耗占比**、环比、瀑布图、结构图：由 `platforms` 与 `MTD_DAYS` 自动计算。  
- 走势 **虚线预估**：由 `week` + 内置公式自动计算。  
- 导出 PNG：右上角「导出图片」（首次需联网加载截图组件）。

## 可选：让人工代填

把飞书「其余API日耗」链接和 **截止日（昨天）** 发给维护人，可代为更新 `platforms`、`week` 与日期文案，你本地保存并刷新浏览器即可。

当前 HTML **不会**自动连接飞书；若需全自动同步，需另做脚本或接口（未包含在本单文件中）。
