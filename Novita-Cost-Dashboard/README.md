# Novita (NO原始表) - 费用趋势看板

与 `API-Cost-Dashboard` 同结构，数据来自飞书 **AI-平台消耗 → NO原始表**（单位：美元）。

## 打开方式

双击 `Novita-Cost-Dashboard.html`，保存后 **Ctrl+F5** 强刷。

## 费用项与飞书列

| 看板项 | 飞书列 |
|--------|--------|
| LLM | D 列 |
| sd | E 列 |
| GPU (按需) | F 列 |
| GPU (按需存储) | G 列 |
| GPU 固定 | H 列 |

## 更新字段

- `week`：最近 7 天日耗（当前 10/12–10/18，随截止日滚动）
- `d27` / `d26`：截止日 / 前一日（当前 10/18 / 10/17）
- `mtd`：表内「10月 当期合计数」（10/19 起为空，不计入）
- `augSame`：表内 340 行「10月上月同期合计数」（9/1–9/18）
- `augFull`：9 月「09月 当期合计数」
- `est`：LLM / sd / GPU按需存储 = `mtd ÷ MTD_DAYS × 31`；GPU（按需）+ GPU 固定合计按机器表 10 月总费用 $36,640（140 台），再按当期实际占比拆开
- `MTD_DAYS`：截止日是本月第几天（截止 10/18 → 18）

## GPU 固定（包月）

- **消耗统计**（顶部、瀑布、占比、明细）：GPU 固定与其它项一样，填 `platforms` 里该行，数据来自 **NO原始表** 合计行/日耗。
- **日走势图**：不展示 GPU 固定（`fixedGpu: true` 且无 `week`）。
- **机器数量（按月）**：独立区块，只改 `GPU_MACHINES`（NOVITA预估），**不覆盖** `platforms` 里的消耗数字。
