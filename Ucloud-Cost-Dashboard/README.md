# UCloud - 费用趋势看板

与 `Novita-Cost-Dashboard` 同结构，数据来自飞书 **AI-平台消耗 → ucloud**（单位：人民币，截至 **9/30**）。

## 打开方式

双击 `Ucloud-Cost-Dashboard.html`，或根目录 `ucloud-看板.html`。保存后 **Ctrl+F5** 强刷。

## 费用项与飞书列

| 看板项 | 飞书位置 |
|--------|----------|
| GPU (按需) | D 列日耗；9 月合计 = 53.9；8 月合计 = 352.03（表内仅 8/29–8/31） |
| GPU 固定 | 右侧「机器数量（按月）」9 月总费用 = 86,918.92（38 台），8 月 = 55,697.14（30 台），不在日走势里 |

## 口径

- `week`：按需近 7 日（9/24–9/30），D 列；9/28 = 21.72，9/29 = 0.02，9/30 = 4.64，其余为 0
- `mtd` 按需：9/1–9/30 合计 53.9
- `augSame` 按需：8 月合计 352.03
- 9 月已完结，不再把按需按日外推成整月预估
- GPU 固定按整月计入：9 月 86,918.92，8 月 55,697.14
- 按需日均：9 月按 30 天，8 月按表内 3 天

## 机器数量

只改 `GPU_MACHINES`。`sepQty` = 9 月，`augQty` = 8 月。总费用用表内合计 `SEP_FIXED_BILLED` / `AUG_FIXED_BILLED`，不用「单价 × 台数」。
